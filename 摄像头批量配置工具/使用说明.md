# 摄像头批量配置工具 · 使用说明

对**宇视（UNV）摄像头**做 Excel 批量配置：读取表格里的 IP，用浏览器自动化逐台登录 Web 管理页并下发参数，最后输出结果表。

---

## 1. 目录结构

```
摄像头批量配置工具\
├── batch_configure_unv_cameras.py   主程序
├── camera_batch.xlsx                【输入】待配置摄像头清单
├── camera_batch_results0722.xlsx    【输出】配置结果
└── 使用说明.md                      本文件
```

---

## 2. 输入文件格式

`camera_batch.xlsx` 目前列示例：

| IP | 设备型号 | 版本信息 |
| --- | --- | --- |
| 172.17.116.101 | IPC2xx | 1.0.0 |

- **`IP` 列必需**；其余列可缺。
- 若表格里提供用户名/密码列，会优先使用；否则用命令行传入的默认账号密码。

---

## 3. 运行

```powershell
cd d:\pythonProject3\摄像头批量配置工具

& "d:\pythonProject3\venv\Scripts\python.exe" batch_configure_unv_cameras.py
```

### 可选参数
| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-i, --input` | `camera_batch.xlsx` | 输入 Excel |
| `-o, --output` | `camera_batch_results0722.xlsx` | 结果 Excel |
| `-u, --username` | `admin` | 默认登录用户名 |
| `-p, --passwords` | `admin!123,admin@123,admin！123,admin＠123` | 密码候选，逗号分隔，会逐个尝试 |
| `--headless` | 关闭 | 启用无头模式（不弹浏览器） |
| `-c, --concurrency` | `10` | 并发处理数量 |

示例：
```powershell
# 不弹浏览器、并发 5、指定输入输出
& "d:\pythonProject3\venv\Scripts\python.exe" batch_configure_unv_cameras.py --headless -c 5 -i camera_batch.xlsx -o camera_batch_results0722.xlsx
```

## 4. 依赖：Playwright 浏览器内核

> ⚠️ 当前 `d:\pythonProject3\venv` 里**尚未安装 playwright**，首次使用前请先执行下面两条命令。

首次使用（或提示 `Executable doesn't exist`）时，需要安装：

```powershell
# 1) 安装 playwright Python 包
& "d:\pythonProject3\venv\Scripts\python.exe" -m pip install playwright

# 2) 安装 Chromium 内核到项目根的 ms-playwright
$env:PLAYWRIGHT_BROWSERS_PATH='d:\pythonProject3\ms-playwright'
& "d:\pythonProject3\venv\Scripts\python.exe" -m playwright install chromium
```

- 浏览器内核默认使用项目根目录的 `ms-playwright`（脚本会自动识别；若本目录下也有 `ms-playwright` 则优先用本目录）。

## 5. 常见问题

**Q：大量设备登录失败？**
先确认密码候选是否覆盖现场密码（用 `-p` 传入），以及摄像头 Web 管理页可正常打开。

**Q：并发调多少合适？**
默认 10。设备性能弱或网络一般时建议降到 `-c 3 ~ 5`。

**Q：输出里每行的状态怎么看？**
结果表会带每台设备的执行状态与 message（如“参数修改并校验成功”），失败的会写明原因。
