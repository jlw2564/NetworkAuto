# 人员权限提取工具 · 使用说明

根据**在职人员表**中的人员编号，去**权限表目录**里匹配 `人员编号.xls` 权限文件，汇总提取成 Excel，并区分「匹配上」与「未匹配」。

---

## 1. 目录结构

```
人员权限提取工具\
├── extract_permissions_by_emp.py   主程序（提取汇总）
├── chk_perm_result.py              结果自检（输出文件是否存在、Sheet 与行数）
├── _rewrite_unmatched_xlsx.py      由汇总结果重新生成“未匹配权限表”
├── _verify_outputs.py              结果校验报告（写入 perm_verify_report.txt）
├── perm_run.log                    历史运行日志
├── perm_verify_report.txt          历史校验报告
└── 使用说明.md                     本文件
```

> 运行前请把数据放到本目录（都是相对路径，**必须在当前目录下执行**）：
> - `在职人员.xlsx`（含“人员编号”列）
> - `权限表\`（里面是 `人员编号.xls` 文件）

---

## 2. 主程序用法

```powershell
cd d:\pythonProject3\人员权限提取工具

& "d:\pythonProject3\venv\Scripts\python.exe" extract_permissions_by_emp.py
```

### 可选参数
| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--emp` | `在职人员.xlsx` | 在职人员表路径 |
| `--perm-dir` | `权限表` | 权限表原始目录 |
| `--output` | `在职人员权限提取结果.xlsx` | 汇总权限输出 |
| `--unmatched` | `在职人员-未匹配权限表.xlsx` | 未匹配人员输出 |
| `--matched-perm-dir` | `结果` | 匹配上的权限表拷贝目录 |
| `--unmatched-perm-dir` | `未匹配权限表` | 未被任何人命中的权限表单独存放目录 |

示例：
```powershell
& "d:\pythonProject3\venv\Scripts\python.exe" extract_permissions_by_emp.py --emp 在职人员.xlsx --perm-dir 权限表 --output 在职人员权限提取结果.xlsx
```

### 输出
| 文件 / 目录 | 内容 |
| --- | --- |
| `在职人员权限提取结果.xlsx` | 多 Sheet 汇总（人员权限汇总 / 未匹配人员 / 权限读取错误 等） |
| `在职人员-未匹配权限表.xlsx` | 未匹配人员清单 + 需要补权限的人员 |
| `结果\` | 按人员匹配成功的权限表副本 |
| `未匹配权限表\` | 没有任何在职人员命中的权限表 |

## 3. 辅助脚本

| 脚本 | 用途 | 命令 |
| --- | --- | --- |
| `chk_perm_result.py` | 检查输出文件是否存在、大小、Sheet 结构与行数 | `python chk_perm_result.py` |
| `_rewrite_unmatched_xlsx.py` | 由汇总结果重建“未匹配权限表”（自动改名备份旧文件） | `python _rewrite_unmatched_xlsx.py` |
| `_verify_outputs.py` | 生成校验报告并写入 `perm_verify_report.txt` | `python _verify_outputs.py` |

## 4. 常见问题

**Q：提示找不到权限表目录？**
确认目录名与 `--perm-dir` 一致，且权限文件命名为 `人员编号.xls/xlsx`。

**Q：为什么必须在当前目录运行？**
主程序的默认路径是相对的。若要在别处运行，请用 `--emp` / `--perm-dir` / `--output` 显式指定绝对路径。

**Q：输出 Excel 打不开 / 被占用？**
脚本会先删除或改名旧文件；若被 Excel 打开会失败，请先关闭再重跑。
