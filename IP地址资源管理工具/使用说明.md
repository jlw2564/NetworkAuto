# IP 地址资源管理工具 · 使用说明

读取 `端口数据.xlsx` 里的终端 IP，按网段分组生成 **IP 地址资源管理表**（含资源表 + 统计图表）。

---

## 1. 目录结构

```
IP地址资源管理工具\
├── generate_ip_table.py           主程序
├── IP地址资源管理表.xlsx           【输出】IP 资源表 + 统计图表
└── 使用说明.md                     本文件
```

---

## 2. 数据来源（重要）

本工具**不单独采集数据**，它读取的是由「交换机端口管理工具」产生的 `端口数据.xlsx`（Sheet：`正常数据`）。

脚本按以下顺序自动查找 `端口数据.xlsx`：

1. 本目录 `IP地址资源管理工具\端口数据.xlsx`
2. 同级目录 `交换机端口管理工具\端口数据.xlsx`

> 即：默认情况下只要用「交换机端口管理工具」跑出过端口数据，这里就能直接生成；否则请手动把 `端口数据.xlsx` 复制到本目录。

---

## 3. 运行

```powershell
cd d:\pythonProject3\IP地址资源管理工具
& "d:\pythonProject3\venv\Scripts\python.exe" generate_ip_table.py
```

运行后在本目录生成 `IP地址资源管理表.xlsx`，包含：

| Sheet | 内容 |
| --- | --- |
| IP资源表 | 按 `x.x.x.0` 网段分组，列出每个 IP 的占用情况与设备名称/备注 |
| 统计图表 | 各网段已用/空闲/总数/使用率及图表 |

另外脚本内置了 `172.17.115.0`、`172.17.116.0` 两个固定网段，方便对照核心网段。

---

## 4. 常见问题

**Q：报错“未找到 端口数据.xlsx”？**
先用「交换机端口管理工具」跑一次；或把 `端口数据.xlsx` 复制到本目录。

**Q：`端口数据.xlsx` 里没有 `正常数据` Sheet？**
说明版本不匹配，请用本工具集里的「交换机端口管理工具」重新生成。
